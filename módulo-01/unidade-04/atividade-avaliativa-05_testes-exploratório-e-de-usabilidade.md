# Análise Exploratória e de Usabilidade do Sistema Clínica Psi

## Pontos que eu exploraria livremente no sistema

### 1. Perfis e permissões

Verificaria se cada perfil, como Administrador, Psicólogo, Funcionário e Cliente, realmente possui apenas os acessos permitidos.

### 2. Cadastro e exclusão de usuários

Testaria a criação, edição e exclusão de usuários para verificar se as alterações são realmente aplicadas no sistema.

### 3. Agendamentos e agenda profissional

Exploraria a criação, edição, cancelamento e reagendamento de consultas, verificando possíveis conflitos de horários.

### 4. Prontuários e evoluções de sessão

Verificaria se os dados são salvos corretamente e se apenas usuários autorizados conseguem acessar informações dos pacientes.

### 5. Navegação entre os módulos

Exploraria livremente os itens do menu lateral, verificando se todos funcionam corretamente e se levam às páginas esperadas.

## Possíveis problemas de usabilidade

### 1. Menu lateral muito extenso

O sistema possui uma grande quantidade de funcionalidades no menu lateral, como **Pacientes, Psicólogos, Funcionários, Agendamentos, Prontuários, Financeiro, Suprimentos e Análises**.

#### Impacto no usuário

O usuário pode ter dificuldade para localizar rapidamente uma funcionalidade específica, especialmente quem está utilizando o sistema pela primeira vez.

### 2. Muitos itens exibidos ao mesmo tempo

Grande parte das funcionalidades fica disponível diretamente no menu, deixando a navegação visualmente extensa.

#### Impacto no usuário

Pode causar confusão e aumentar o tempo necessário para encontrar determinada funcionalidade.

### 3. Falta de destaque entre algumas categorias

As categorias como **Financeiro, Suprimentos e Análises** possuem uma diferenciação visual mais discreta em relação aos itens do menu.

#### Impacto no usuário

O usuário pode não perceber facilmente onde uma categoria começa ou quais funcionalidades pertencem a ela.

### 4. Possível dificuldade para visualizar todos os itens

Como existem muitos módulos, especialmente em telas menores, parte do menu pode ficar fora da área visível, exigindo rolagem.

#### Impacto no usuário

Funcionalidades importantes podem ficar escondidas, dificultando o acesso e tornando a navegação mais lenta.

### 5. Dashboard com pouco detalhamento

A tela inicial apresenta informações como quantidade de consultas cadastradas, pacientes ativos e módulos disponíveis, mas pode não mostrar informações mais úteis para o trabalho diário.

#### Impacto no usuário

O usuário pode precisar navegar por vários módulos para encontrar informações importantes, como próximos atendimentos ou tarefas pendentes.
